# Security Policy

## Supported Versions

Security fixes are provided for the latest code on the `main` branch. Older
commits and releases may not receive security updates.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through the repository’s
**Security** tab using **Report a vulnerability** (GitHub Private Vulnerability
Reporting), if that option is available. Do not report vulnerabilities in a
public issue.

Include:

- Affected version or commit
- Steps to reproduce and the expected security impact
- Any safe proof of concept that does not access other people’s data

Please do not include passwords, API keys, personal documents, chat exports, or
other private data in a report.

The maintainers will review reports and follow up through GitHub. Please allow
time for investigation and a fix before publicly disclosing the issue.
